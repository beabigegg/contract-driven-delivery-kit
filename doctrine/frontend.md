# Frontend doctrine

- CDD-FE-001: Do not infer response shape from one backend implementation branch; consume generated boundary types where supported.
- CDD-FE-002: Preserve loading, empty, error, permission, slow, and partial-data semantics.
- CDD-FE-003: Prefer native controls and existing design-system components before custom interaction primitives.
- CDD-FE-004: Accessibility and keyboard behavior are functional requirements, not visual polish.
