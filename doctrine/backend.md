# Backend doctrine

- CDD-BE-001: Keep transport controllers thin and put domain behavior behind explicit service boundaries.
- CDD-BE-002: Validate untrusted input at the boundary and return standardized contracted errors.
- CDD-BE-003: Treat transactions, connection budgets, N+1 behavior, idempotency, retries, and timeouts as production correctness.
- CDD-BE-004: Cache, database, fallback, worker, and async branches must serialize compatible contracted shapes.
