# Testing doctrine

- CDD-TEST-001: Map observable acceptance criteria to tests before implementation when feasible.
- CDD-TEST-002: Run the narrowest trustworthy test first, then expand according to affected surfaces and risk.
- CDD-TEST-003: A required failure cannot be waived as pre-existing; fix it, expand scope, or track it separately.
- CDD-TEST-004: Evidence must bind command, result, source state, contract state, and run identity.
