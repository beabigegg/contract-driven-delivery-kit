# Core engineering doctrine

- CDD-CORE-001: Prefer the smallest change that satisfies the approved objective without weakening contracts, tests, security, or observability.
- CDD-CORE-002: Reuse an existing stable abstraction before adding a parallel implementation.
- CDD-CORE-003: Unknown impact is a reason to expand evidence or escalate profile, never to claim safety.
- CDD-CORE-004: Completion is determined by executable evidence and configured approval, not agent confidence.
