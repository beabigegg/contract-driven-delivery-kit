# Interaction and accessibility doctrine

- CDD-UX-001: Preserve human-confirmed intent and distinguish user decisions from agent suggestions.
- CDD-UX-002: Every control maps to one user intent and every material state has an observable discriminator.
- CDD-UX-003: Review interaction semantics separately from pixel/layout review.
- CDD-UX-004: Do not invent approval, acceptance, or design provenance.
